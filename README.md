# 🎂 Felices 23, Vanessa ✨ | Experiencia Interactiva de Cumpleaños

Una aplicación web interactiva (Single Page Application) moderna, elegante y totalmente adaptada a dispositivos móviles y ordenadores para celebrar los 23 años de Vanessa.

---

## 🎨 Características

- **Diseño Editorial & Glassmorphism:** Paleta en tonos champagne, oro rosa, marfil y fondo carbón aterciopelado con partículas doradas flotantes.
- **🪙 Mecánica de Rasca y Gana en Canvas:** Lienzo táctil y para ratón con textura dorada metalizada, auto-revelación al 50% con sonido mágico arpegiado (Web Audio API) y confeti dorado (`canvas-confetti`).
- **🎁 7 Regalos Interactivos:**
  1. **Maquillaje:** Kit y sesión de cosméticos de belleza.
  2. **Sesión de Masaje:** Recomendaciones de centros de relax con valoraciones 5⭐ (*ARomaMatSens & Terapias Bienestar Esther Madrid*).
  3. **Paquete Uno:** Caja regalo exclusiva con lazo de seda.
  4. **Pegatina Camino de Santiago:** Ilustración conmemorativa personalizada con el C.D. Leganés y la Catedral de Santiago.
  5. **Paquete Dos:** Caja regalo boutique marfil y oro.
  6. **Carta Romántica:** Escrita a mano en papel con sello de lacre.
  7. **Escapada a Salamanca (Gran Final):** Rasca multinivel de 3 pistas (*Pista 1: Hornazo de Salamanca -> Pista 2: Bandera de Salamanca -> Pista 3: Pase VIP / Tarjeta de Embarque a Salamanca*).
- **Persistencia de Estado:** Guarda los regalos descubiertos en `localStorage` y permite rascar de nuevo o reiniciar el progreso.

---

## 🚀 Instalación y Ejecución

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Compilar para producción:**
   ```bash
   npm run build
   ```
